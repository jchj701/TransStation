# 中转站 TransStation

> Windows 上的“信息中转站”：正在别的应用里干活时，按住文件、文字、链接或图片拖动，
> 按一下快捷键唤出面板，松手即存入；需要时拖出、双击或复制即可取用。
> 全程不打断当前工作 —— 窗口平时不存在，只有托盘图标驻留后台。

单文件程序，**任何 Win10 / Win11（64 位）双击即用**，不依赖 Python 或任何系统组件。

---

## 快速开始

**获取程序**：优先从 GitHub [Releases](https://github.com/jchj701/TransStation/releases)
下载最新 `TransStation.exe`（页面同时提供 SHA256 校验值，可用
`certutil -hashfile TransStation.exe SHA256` 核对）。也可自行构建，见文末“开发者信息”。

1. 把 `TransStation.exe` 放到任意位置（桌面、U 盘都行），**双击启动**；
2. 程序驻留系统托盘（右下角图标），无主窗口；
3. 在任意应用里按住内容拖动，途中按 **`Ctrl+Alt+T`**，面板出现在鼠标旁；
4. 把内容拖到面板上松手 → 存入成功，面板自动收起。

- 再次按 `Ctrl+Alt+T` 或按 `Esc` 可随时收起面板；
- 数据自动保存在 **exe 同目录的 `data/` 文件夹**：备份/换机 = 整体拷贝 `data/`；
  升级版本 = 用新 exe 替换旧 exe、保留 `data/` 不动。

## 它能存什么

| 类型 | 说明 |
| --- | --- |
| 📄 文件 / 文件夹 | 只记录路径，绝不复制或移动你的原文件 |
| 🖼 图片 | 来自资源管理器的图片记录路径并显示缩略图；来自网页/剪贴板的图片会自动本地镜像一份 |
| 🔗 链接 | 保存地址与网页标题，双击用默认浏览器打开 |
| 📝 文本 | 保存全文，可在面板内查看/编辑；可开启“镜像为 .txt” |

存不进去的（例如个别应用不支持“拖出”，如 Snipaste 置顶贴图）：在该应用里 **Ctrl+C 复制 → 呼出面板 → 点面板上的“从剪贴板添加”**，同样支持文本/文件/图片/链接。

## 交互模型（按一次就够）

| 情况 | 行为 |
| --- | --- |
| 拖动途中按一次快捷键 | 面板出现在鼠标旁，固定不动 |
| 内容拖到面板上松手 | 高亮“松开鼠标存入”→ 存入提示（可撤销）→ 自动收起 |
| 拖到面板外松手（想重拖） | 面板保持等待，重新拖入即可 |
| 呼出后一直没拖入 | 约 6 秒无任何活动自动收起 |
| 焦点切去其它窗口再回来 | 面板仍在等待（不会因切窗口消失） |
| 钉住面板（标题栏📌） | 常驻不自动收起，可拖动到屏幕任意位置 |
| 面板上有内容时 | 双击=默认打开；按住卡片拖到其它应用=取用；右键=更多操作 |

## 取用内容的四种方式

1. **拖出**：按住面板里的卡片，直接拖到资源管理器、聊天窗口、文档编辑器；
2. **双击**：文件用系统默认程序打开、链接用浏览器打开、文本弹窗查看/编辑；
3. **复制/复制路径**：右键菜单，文本/链接/文件都可复制到剪贴板粘贴；
4. **发送到前台窗口**：右键 → 内容写入剪贴板并提示回到目标窗口 `Ctrl+V`；
   如需全自动，可在设置中开启“发送后自动按 Ctrl+V”（默认关闭，属可选项）。

## 日常管理

- **搜索**：面板顶部搜索框，按标题/正文/备注/链接地址过滤；
- **筛选**：全部 / 文件 / 图片 / 链接 / 文本；
- **整理**：右键卡片 → 置顶 / 编辑备注 / 修改类型 / 删除；
- **回收站**：删除的条目保留 30 天，托盘菜单“回收站”里可恢复或彻底删除；
- **自动记录**：每条内容记录“来自哪个应用”，面板标题栏会显示来源；
- **忽略清单**：设置里可让指定应用不参与记录。

## 数据与隐私

- 全部数据仅存本机 `data/`，**不上传任何云端**；
- 文件条目只记路径不复制文件；文本与链接内容本地存储；
- 每日自动备份到 `data/backups/`（默认保留 7 份）；
- 删除为软删除（回收站 30 天），不会自动清空任何内容；
- 可随时整体拷贝 `data/` 完成备份或迁移。

## 常见问题

**Q：快捷键没反应？**
检查是否被其它软件占用：打开设置 → 呼出与窗口 → 重新点一下快捷键输入框并按下新的组合键（需含 Ctrl 或 Alt）。若提示“已被占用”，换一个组合即可。

**Q：某应用的图片/文件拖不进来？**
少数应用（如 Snipaste 置顶贴图、部分网页控件）不支持“拖出”内容——改用复制：内容上 `Ctrl+C` → 呼出面板点“从剪贴板添加”。

**Q：面板是黑底黑字/颜色不对？**
系统处于深色模式时请使用当前版本（已内置浅色主题强制适配）。

**Q：误删了内容？**
删除先进回收站（保留 30 天）：托盘菜单 → 回收站 → 恢复。

**Q：双击启动没看到窗口？**
正常——它只驻留托盘；按 `Ctrl+Alt+T` 呼出面板。若托盘也没有图标，请到任务栏溢出区查找，或右键任务栏空白处 → 任务栏设置 → 显示隐藏图标确认。

## 路线图

**当前版本（已交付 · M0+M1）**：快捷键呼出-拖放存入-快速取用闭环、托盘常驻、搜索筛选、回收站、来源记录、剪贴板添加、单文件便携、每日备份。

**规划中：**

- **M2 · 后台能力**：链接健康检查（定期检测已存链接，正常/失效/需登录等分级，单条忽略与手动复检）；历史记录查看与修正来源/去向；设置项补全（自动收起时长、记录开关、开机自启等）。
- **M3 · 越用越顺手**：习惯学习与智能建议（面板顶部按“来源应用 × 类型”推荐常用条目并说明理由）；规则映射可视化编辑器（导入/导出 JSON）。
- **M4 · 报表与打磨**：九区块离线 HTML 报表（使用趋势、流转矩阵、链接健康清单等，浏览器打开、断网可用）；新手引导动画；性能与高 DPI 打磨。

明确不做（当前范围外）：自动删除任何内容、云同步、模拟粘贴自动化、停靠/贴边形态、深色模式（预留设计）。
