# TransStation 真机验收清单（第一轮：M0+M1）

> 用途：本机无法自动化模拟“跨应用拖放”，以下每项需在真实 Windows 桌面上人工验证。
> 每项记录：✔ 通过 / ✘ 失败（附现象与复现步骤）/ — 不适用。

## 0. 准备
- [ ] `python main.pyw` 启动成功，托盘出现图标；重复双击运行第二份 → 只唤醒第一份（面板弹出），无第二个进程。
- [ ] 托盘提示文案包含当前呼出快捷键（默认 Ctrl+Alt+T）。
- [ ] 项目根目录出现 `data/`：内含 `settings.json`、`db/transstation.db`（首次退出后）。

## 1. 呼出 / 收起（M0）
- [ ] 在任何应用按 Ctrl+Alt+T → 面板在鼠标旁弹出（不挡鼠标），始终置顶。
- [ ] 面板出现后 150ms 内淡入；再次按 Ctrl+Alt+T → 淡出收起。
- [ ] 按 Esc → 收起（面板需处于焦点状态）。
- [ ] 点击其它应用窗口（非面板区域）→ 面板自动收起。
- [ ] 点标题栏“钉住”后：存入内容/点击外部均不自动收起；再点解除钉住恢复自动收起。
- [ ] 钉住后拖动面板到别处，收起再呼出（钉住状态）→ 回到上次位置。
- [ ] 拖动右下角把手改变大小 → 重新呼出保持新尺寸；设置里关闭“记忆几何”后不再记忆。
- [ ] 多显示器：在副屏按热键 → 面板完整落在副屏工作区内，不被截断。
- [ ] 高分屏 125% / 150% 缩放：面板清晰（无模糊），缩略图/图标不糊。
- [ ] 系统“辅助功能→视觉效果→动画效果”开启后：呼出收起动画消失（直接显隐）。

## 2. 首次上手
- [ ] 全新数据目录首次呼出 → 显示三步引导；点“开始使用”后不再出现。
- [ ] 空状态显示插图与快捷键提示文案；点“从剪贴板添加”大按钮行为正确。

## 3. 拖入存入（M1 核心）
- [ ] **资源管理器**：按住文件拖动途中按 Ctrl+Alt+T → 面板出现在鼠标旁且未抢焦点（拖拽未被打断）→ 拖到面板上整窗高亮 + “松开鼠标存入”提示 → 松手：提示“已存入：文件名” + 撤销按钮 → 约 2.8s 后面板自动收起（或立即点外部收起）。
- [ ] 一次拖入多个文件 → “已存入 N 项”；列表中逐条可见。
- [ ] 拖入文件夹 → 文件夹图标（非图片类型）出现。
- [ ] 拖入后 3 秒内点“撤销”→ 条目消失（含镜像文件清理）。
- [ ] **拖出取消**：拖拽中面板出现后，把内容拖到面板**外**空白处松手 → 面板收起，内容未存入（可回源应用确认拖拽被系统取消）。
- [ ] **Chrome 拖链接**（地址栏/网页链接）→ 存为“链接”，标题取网页锚文本或域名。
- [ ] **Chrome 拖网页图片** → 存为“图片”，卡片显示缩略图（data/images/ 下生成 PNG 镜像）。
- [ ] **Chrome/记事本选中文字拖动** → 存为“文本”，标题取首行。
- [ ] **微信聊天**：拖聊天里的文本/图片/文件入面板，类型正确。
- [ ] Word/记事本选中文字拖入 → 文本。
- [ ] 拖入面板时从标题栏空白处拖过也能触发高亮（整窗可投）。

## 4. 剪贴板添加
- [ ] 复制一段文字 → 呼出面板 → 点剪贴板按钮 → 存为文本。
- [ ] 复制单个 http(s) 链接 → 识别为链接。
- [ ] 复制文件（资源管理器 Ctrl+C）→ 存为文件。
- [ ] 浏览器“复制图片” → 存为图片并镜像。
- [ ] 剪贴板为空时点按钮 → 提示“剪贴板为空”。
- [ ] 存入后不自动收起（与拖入不同），可连续添加。

## 5. 浏览 / 搜索 / 管理
- [ ] 类型筛选 chips：全部/文件/链接/文本/图片 各自过滤正确；再次点选同类可取消？—— 需为单选（点其它才切换）。
- [ ] 搜索框：按标题、正文、备注、URL 命中；清空恢复。
- [ ] 卡片显示：类型图标、标题、时间与来源/路径；图片条目左缩略图。
- [ ] 双击文件 → 系统默认程序打开；双击链接 → 默认浏览器；双击文本 → 内容弹窗（可编辑保存，保存后标题同步首行）；双击失效路径文件 → 提示不存在。
- [ ] 右键 → 打开/复制/复制路径/发送到前台窗口/显示文件位置/修改类型/查看编辑内容(文本)/编辑备注/置顶/删除 —— 各动作生效；修改类型后图标/双击行为切换。
- [ ] 右键“显示文件位置”→ 资源管理器打开并选中该文件。
- [ ] 键盘：方向键在列表移动；Enter 打开；Ctrl+F 聚焦搜索框；Esc 收起。

## 6. 拖出取用（M1 核心）
- [ ] 面板拖**文件**卡片到资源管理器窗口 → 复制到目标目录（CF_HDROP）。
- [ ] 拖**文件**到微信聊天窗口 → 发送文件。
- [ ] 拖**文本**卡片到记事本/Word → 插入文本。
- [ ] 拖**链接**卡片到 Chrome 地址栏/新标签 → 打开该网址。
- [ ] 拖**图片**卡片到 Word / 微信 → 图片插入/发送。
- [ ] 拖到桌面 → 生成文件副本（或系统默认行为）。
- [ ] 拖出到自身面板 → 无副作用（不算取用）。
- [ ] 拖出完成后：底部状态栏“本周使用 N 次”计数 +1（open/drag_out/send/copy 计入）。

## 7. 记录与忽略
- [ ] 拖入后卡片副行显示来源应用（如“来自 Chrome”）；标题栏 chip 同步。
- [ ] 设置 → 忽略清单添加 `chrome.exe` → 之后 Chrome 中存入/取用的记录不再写入（条目副行也不显示来源），其余应用正常。
- [ ] 双击打开文件后约 1 秒，去向被记录（可在 db 的 usage_log 表中查到 dst_app；供后续统计）。

## 8. 删除 / 回收站
- [ ] 右键删除 → 列表移除 + “已删除（可在回收站恢复）”提示，点撤销即恢复。
- [ ] 设置入口旁的回收站：托盘菜单当前未提供 → 通过说明中的方式打开回收站窗口：
  临时验收路径：在设置界面旁暂无入口时，先通过右键删除后看提示；
  回收站窗口入口将由托盘“打开报表”旁补充（M1 验收前请先确认可用）——如缺失记为问题。

## 9. 设置
- [ ] 快捷键改为 Ctrl+Shift+T → 应用；旧键失效新键生效；改回默认。
- [ ] 快捷键被其它程序占用时（可先用其它工具占住）→ 设置保存报错且原快捷键保持可用。
- [ ] 弹出偏移 / 自动收起延时 / 自动收起开关 / 面板宽高生效。
- [ ] 发送到前台窗口：
  - 默认：呼出面板前停留在某应用 → 右键“发送到前台窗口” → 内容进剪贴板 + 提示回该应用按 Ctrl+V；
  - 开启“自动 Ctrl+V”后 → 回到目标应用并自动完成粘贴。
- [ ] 忽略清单增删生效（见第 7 节）。
- [ ] 备份保留份数修改保存成功；“立即备份”→ data/backups/backup-日期.zip 生成。
- [ ] 文本镜像开启后再存入文本 → data/text/ 生成对应 .txt。

## 10. 数据迁移（重点，便携定位）
- [ ] 设置 → 数据目录“更改…”→ 选同盘空目录 → 确定后目录内容整体搬移（含 db/镜像/备份），列表数据完整；bootstrap 写入新路径；重启应用仍指向新目录。
- [ ] 目标目录非空时保存 → 报错不迁移。
- [ ] 整体拷贝 `data/` 到另一个位置/机器 → 程序正常读取（便携迁移）。

## 11. 稳定性
- [ ] 长时间挂托盘不崩溃；面板反复呼出/收起 50 次无异常。
- [ ] 2000 条条目时（可临时用脚本灌数据）搜索/滚动流畅无卡死。
- [ ] 退出（托盘→退出）进程干净结束，无残留 python/pythonw 进程。
